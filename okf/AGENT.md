# Agent (agent/, crate `agent`, binary published as `desk_ctrl_agent`)

Display branding: **ViL Agent** in window title, header, tray tooltip and Linux launchers. Tray restore entry: Show ViL. Approved icon embedded from `branding/vil-icon-256.png` in window/tray; Windows GNU build embeds `branding/vil-icon.ico` via `build.rs`/`vil.rc` (requires windres). Existing config, registry and executable identifiers are retained for compatibility.

Deps: eframe 0.36 (GUI), evdev, tokio + tokio-tungstenite, zbus 5 (BlueZ + AT-SPI), qrcode, libc. Linux only.
Run: `./desk_ctrl_agent` (window) or `--headless` (prints token). Needs `/dev/uinput` access (`output/setup_laptop.sh`).

## Environment variables
| Var             | Effect                                                              |
| --------------- | ------------------------------------------------------------------- |
| `DESK_PORT`     | Wi-Fi port (default 8765)                                           |
| `DESK_TOKEN`    | fixed pairing token (default: random 8 hex per start)               |
| `DESK_NO_USB=1` | start with USB auto-connect off (demos, tests next to a real agent) |
| `DESK_ADB`      | path of the `adb` program (default `adb`)                           |
| `DESK_DEBUG`    | focus decisions printed to stderr                                   |

## Windows build (desk_ctrl_agent.exe)
One code base, split with `cfg(unix)` / `cfg(windows)`; Windows-only files are swapped in with `#[path]` in main.rs: `bluetooth_win.rs` (stub: "not available on Windows yet"), `focus_win.rs` (stub, no auto-keyboard), `portowner_win.rs` (IP Helper `GetExtendedTcpTable`, not `netstat`: its words are localised), `autostart_win.rs` (HKCU Run value `DeskCtrlAgent`), `winproc.rs` (no console window for child programs). In shared files: `inject.rs` uses `SendInput` with virtual-key codes (`hid::hid_to_vk`; the grey keys get the extended flag, lock = `LockWorkStation`, brightness / mic mute have no key), `leds.rs` uses `GetKeyState`, `levels.rs` reports "unknown" (no volume / brightness percentages yet), `identity.rs` the registry `MachineGuid` (via `reg query`), `server.rs::random_bytes` `BCryptGenRandom`, `tokenstore.rs` `%APPDATA%\deskctrl\token`, `usb.rs` prefers an `adb.exe` next to the agent. Voice is off (no helper path on Windows). The window tries wgpu first and OpenGL (glow) second (`main.rs`), for PCs without a usable Vulkan / DX12 driver. Release builds use the GUI subsystem (no console; `--headless` prints nothing there).

## Pairing token (agent/src/tokenstore.rs)
The token is kept in `$XDG_CONFIG_HOME|~/.config/deskctrl/token` (dir 0700, file 0600, atomic write) and is the same at every start, so phones stay paired across restarts, reboots and autostart. 16 hex chars (8 random bytes; was 8 chars when it was per-run). "New token" in the window writes a new one on purpose. `DESK_TOKEN` overrides it (tests, demos) and is never saved. A file with anything but 8-128 letters/digits is replaced. Phones paired with an older per-run token must pair once more (USB re-pairs by itself).

## Autostart (agent/src/autostart.rs, Settings > Start-up)
"Start the agent when I log in" = the file `$XDG_CONFIG_HOME|~/.config/autostart/deskctrl-agent.desktop` exists (the file is the setting, no config entry): `Exec=<quoted current_exe> [--minimized]`, `X-GNOME-Autostart-Delay=5`. "Start minimised" adds `--minimized` (uses the tray when enabled, otherwise the taskbar). `autostart::refresh()` runs at every start and repoints the entry at the running program ONLY if the program the entry names no longer exists (agent moved/deleted; keeps the minimised choice). A test or demo copy of the agent must never take over the user's autostart (it did once: a screenshot run rewrote the entry to `agent/target/release/agent`; repaired by hand). A desktop-disabled entry (`Hidden=true`, `X-GNOME-Autostart-enabled=false`) counts as off. The entry points at the program that is running when the box is ticked: run the installed copy (`/usr/local/bin/desk_ctrl_agent`) for a stable path. Tests use a temp `XDG_CONFIG_HOME`.

## Minimize to tray (agent/src/tray.rs)
Settings > Window: "Minimize to tray" (default off), saved in the agent config directory as `minimize-to-tray` (`true`/`false`). Enabling creates a native tray icon with Show DeskCtrl and Close application; Windows also supports double-click to restore. Minimizing or closing the window hides it while the server keeps running. Close application sets a shared quit flag before requesting window close, so the close interceptor allows a full exit. With tray disabled or unavailable, window close exits normally. `--minimized` uses the tray when enabled. Creation errors appear in Settings. Linux uses StatusNotifierItem (tray-icon's KSNI backend, no GTK dependency); the desktop needs a compatible tray host (GNOME may need an AppIndicator extension). Windows uses its notification area. Headless mode has no tray.

## Voice (agent/src/voice.rs, agent/voice/)
`Engine` keeps one Python helper (`voice_helper.py`: Whistle speech->text, Needle 3 text->action, `cactus-needle` >= 3.2) loaded, one JSON line in / out, started inside `systemd-run --user --scope -p MemoryMax=1536M -p MemorySwapMax=0 -p TasksMax=128 -p CPUWeight=1 -p IOWeight=1` + `chrt -i 0` (idle scheduling class; fallback `nice -n 19`; without systemd `ulimit -v 8G`). NEVER a CPU quota or core mask: the engine starts one busy-waiting, core-pinned thread per core (`sysconf(NPROCESSORS)`), so fewer cores = minutes per recognition (measured: 2 of 4 cores = 3x slower; quota 150% on 12 cores = no answer for 4+ min). The helper removes truncated model files (`heal_cache`), killed after 180 s of silence. `VoiceSession` (one per phone connection, Wi-Fi and Bluetooth) collects audio (cap 30 s), writes a 0600 temp WAV, asks the helper, and sends the JSON back in 0x15 pieces. The agent never presses keys for voice: the phone decides what a phrase means.
Install: `setup_voice.sh` (venv in `~/.local/share/deskctrl/voice/env`, models downloaded once; needs `python3-venv` or `uv`). `Engine::prepare()` rewrites `voice_helper.py` there at every start. Env: `DESK_NO_VOICE=1` off, `DESK_VOICE_HELPER=<program>` use another helper (tests). Tests: `voice.rs` + one Wi-Fi and one Bluetooth test with a fake shell helper (`fake_engine`).

## Window layout (cleaned up 2026-10-19)
Default 720x420, minimum 680x380. Connect tab: left column ~200 px with the QR code centred, a thin line, right column with ONE grid (rows 26 px): Wi-Fi / Port / Token on the left, a divider, Bluetooth / USB pills on the right (all pills 84 px wide: `look::status_pill`); under it a rule and the "Connected Devices" table whose header, rows and empty message share the columns icon (34 px) / name / IP (`devices_table(width)` gets `right.width()`, never `ui.available_width()`, which grows when a grid overflows). A port problem shows as one tinted block under the header. Settings is a scrollable window (max height = window - 64 px, width 300). Screenshots: `DESK_SHOW=settings|log` opens that view at once; `Xvfb` + `WGPU_BACKEND=gl` + `xwd`; set `XDG_CONFIG_HOME` to a temp dir so the run cannot touch the real autostart / token files.

## Behaviour notes
- `start()` binds first; on failure nothing else starts (Start works later). `stop()` joins all threads and removes adb tunnels.
- Tests (`cfg!(test)`) never poll the cable (`usb_auto` false) - a test once paired a real phone.
- Bluetooth "UUID already registered" means another agent owns the BlueZ service (normal when two agents run).
